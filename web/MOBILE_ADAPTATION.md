# Мобильная адаптация новых функций веса

## Выполненные улучшения

### 1. Адаптивная диаграмма веса
- **До 768px (планшеты):**
  - Уменьшен padding диаграммы: `16px` → `12px`
  - Высота графика: `250px` → `180px`
  - Размер шрифта заголовка: `14px` → `13px`
  - Метаданные: `13px` → `11px`
  - Легенда в одну колонку

- **До 600px (телефоны):**
  - Высота графика: `180px` → `160px`
  - Размер шрифта легенды: `11px`
  - Уменьшены отступы

- **До 480px (маленькие телефоны):**
  - Высота графика: `160px` → `140px`
  - Размер шрифта заголовка: `12px`
  - Метаданные: `10px`
  - Минимальные отступы для компактности

### 2. Прогресс-бар
- Увеличена высота: `24px` → `28px` для лучшей видимости на сенсорных экранах
- Добавлена рамка для чёткости контура
- Увеличен размер шрифта: `12px` → `13px`
- Увеличен порог переключения позиции процента: `10%` → `15%`
- Адаптивные отступы на всех размерах экранов

### 3. Настройки веса
- Поля "Стартовый вес" и "Желаемый вес" сгруппированы в блоки
- Каждое поле с собственной кнопкой сохранения
- Более описательный текст кнопок: "Сохранить стартовый вес" / "Сохранить желаемый вес"
- Адаптивные размеры полей ввода для всех экранов
- Предотвращение зума на iOS (font-size: 16px для input)

### 4. Улучшения UX
- Touch-friendly размеры элементов (минимум 28px)
- Чёткие границы для лучшей видимости
- Оптимизированное использование пространства на маленьких экранах
- Сохранение читаемости на всех размерах

## Тестирование

Рекомендуется протестировать на:
- ✅ iPhone SE (375px) — минимальная ширина
- ✅ iPhone 12/13/14 (390px) — стандартный размер
- ✅ iPhone 14 Plus/Pro Max (428px) — большие телефоны
- ✅ iPad Mini (768px) — маленькие планшеты
- ✅ Landscape режим на телефонах

## Breakpoints

```css
/* Планшеты и маленькие ноутбуки */
@media (max-width: 768px) { ... }

/* Телефоны */
@media (max-width: 600px) { ... }

/* Маленькие телефоны */
@media (max-width: 480px) { ... }

/* Горизонтальная ориентация */
@media (max-height: 500px) and (orientation: landscape) { ... }
```
