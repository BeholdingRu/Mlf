# Обновление: Отслеживание прогресса веса

## Что изменилось

### 1. Стартовый вес в диаграмме
Теперь на диаграмме "История веса" (во вкладке "Статистика за всё время") начальная точка берётся из поля **"Стартовый вес"** в настройках.

### 2. Новое поле "Желаемый вес"
В настройках добавлено новое поле **"Желаемый вес"**, в которое вы можете внести желаемое значение веса.

### 3. Индикатор прогресса
Под диаграммой "История веса" теперь отображается шкала прогресса, которая показывает ваш прогресс от **стартового веса** до **желаемого веса** с точностью до сотых процента.

## Как использовать

1. **Откройте настройки** (иконка ⚙️)
2. В разделе **"Вес"**:
   - Включите "Показывать блок с весом в кабинете"
   - Заполните **"Стартовый вес"** — ваш начальный вес
   - Заполните **"Желаемый вес"** — ваша цель
   - Нажмите "Сохранить" для каждого поля
3. Перейдите во вкладку **"Статистика за всё время"**
4. Теперь вы увидите:
   - Диаграмму с начальной точкой (стартовый вес)
   - Шкалу прогресса под диаграммой

## Расчет прогресса

Прогресс рассчитывается по формуле:
```
Прогресс % = (Текущий вес - Стартовый вес) / (Желаемый вес - Стартовый вес) × 100
```

**Примеры:**
- Стартовый вес: 80 кг
- Желаемый вес: 70 кг
- Текущий вес: 75 кг
- Прогресс: (75 - 80) / (70 - 80) × 100 = 50%
