# MLF — трекер ежедневных задач

Веб-кабинет: регистрация по email, ежедневные задачи, статистика за неделю / месяц / всё время, блок веса и шкала «% формирования привычки». Данные хранятся в Supabase.

## 1. Проект в Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните файл `supabase/schema.sql`.
3. В **Authentication → Providers → Email** включите вход по email и паролю.
4. Для сценария «забыли пароль» с **6-значным кодом**:
   - **Authentication → Email Templates → Reset password**
    - В шаблоне должен быть токен, не только ссылка, например: `Ваш код: {{ .Token }}`
    - Сохраните шаблон и проверьте, что письма уходят (для тестов удобен Inbucket в локальном стеке или реальный SMTP).

Если база уже была создана ранее, для каталога продуктов отдельно выполните
`supabase/add_saved_products.sql` в **SQL Editor**.

Чтобы добавить категории к уже сохранённым продуктам, после обновления приложения выполните
`supabase/add_saved_product_categories.sql` в **SQL Editor**. Все существующие продукты будут
перенесены в категорию «Мясо и мясные продукты».

Чтобы добавить флаг «Избранное» к существующему каталогу, также выполните
`supabase/add_saved_product_favorites.sql` в **SQL Editor**.

Чтобы сохранять БЖУ в новых записях потребления, выполните для существующей базы
`supabase/add_daily_food_log_nutrition.sql` в **SQL Editor** после `supabase/add_saved_product_nutrition.sql`.
БЖУ старых записей будут взяты из одноимённых продуктов личного каталога.

Чтобы добавить белки, жиры и углеводы к существующим продуктам, выполните
`supabase/add_saved_product_nutrition.sql` в **SQL Editor**. Для уже сохранённых продуктов
значения будут установлены в `0`; их можно заполнить через редактирование продукта.

Чтобы добавить в настройки город и часовой пояс для отображения времени заката по пятницам
в календаре, выполните `supabase/add_profile_location.sql` в **SQL Editor**.

## 2. Ключи приложения

В каталоге `web` скопируйте `.env.example` в `.env`:

```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
```

URL и anon-ключ: **Project Settings → API**.

## 3. Запуск

Нужен Node.js 20+.

```
cd web
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

## Как устроен кабинет

- **Ежедневные задачи** — отметка один раз в сутки, пункт становится зелёным. Справа шкала привычки: число дней с отметкой / дни из настроек.
- **Неделя** — с понедельника по сегодня, процент = отметки / число прошедших дней недели.
- **Месяц** — с 1-го числа текущего месяца, процент считается так же.
- **Всё время** — сколько дней задача была отмечена.
- **Вес** включается в настройках: слева показывается `значение из настроек > сегодняшняя цифра`. Сегодняшнюю цифру можно ввести, нажав на блок (не чаще раза в сутки; повтор в тот же день заменяет значение). Счётчик дней стартует с даты первой записи веса в настройках.
- **Настройки** (справа сверху) — задачи: добавить, переименовать, удалить, задать дни до 100% шкалы; блок веса: показ и исходная цифра.
